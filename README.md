# A Cara do Pedro

Bem-vindo ao repositório **A Cara do Pedro**, onde compartilho meu site pessoal e o projeto **Lar Sem Fronteiras** – uma iniciativa de alto impacto sustentável e social, voltada para alimentar pessoas e gerar impacto positivo na comunidade.

## Sobre o Projeto

**Lar Sem Fronteiras** é meu projeto de vida, criado para oferecer apoio social e soluções práticas para quem precisa. Este site é a porta de entrada para conhecer o projeto, acompanhar minhas ideias e colaborar com essa iniciativa.

## Tecnologias

- HTML, CSS e JavaScript
- Projeto hospedado no GitHub e Netlify
- Código aberto e adaptável para novos colaboradores
