## 🌱 Sobre o Lar Sem Fronteiras

**Lar Sem Fronteiras** nasceu para gerar transformação na comunidade:  
- Alimentar pessoas em situação de vulnerabilidade  
- Criar soluções sustentáveis e replicáveis  
- Inspirar outros a agir e colaborar  

Este repositório é o ponto de partida para divulgar, expandir e evoluir o projeto.
